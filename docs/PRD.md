# PRD：喵日常（Mia's Cute Planner）

## 1. 项目基本信息

- **项目名称**：喵日常 / Mia's Cute Planner
- **项目类型**：个人生活办公工具（Web 单页应用）
- **目标用户**：咪咪大人本人，后期可分享给朋友使用
- **项目阶段**：V1.0.0 MVP 已达成并发布 ✅
- **开发方式**：Vibe Coding，AI 结对编程
- **当前版本**：v1.0.0 MVP（2026-09-11 发布）

## 2. 产品定位

一个温暖、可爱、无压力的日常计划网页。帮助用户记录当天要做的事、追踪日常习惯、快速记录心情。

核心体验：打开网页 → 看到今天 → 随手记录 → 获得一点小确幸。

## 3. 用户故事

1. 每天早上打开网页，看到今天的待办清单，勾选完成。
2. 做完一件小事后，给习惯打卡，看到数字会动一下有点成就感。
3. 睡前想写一句今天的心情或感恩小事。
4. 刷新页面或关掉浏览器再打开，记录还在。
5. 切换到「看历史」，能翻看前几天的状态。
6. 能把网页链接发给朋友，朋友打开也能看到同款可爱界面（朋友看到的是自己浏览器里的空白数据，不是咪咪大人的数据 —— v2.0 解决）。

## 4. 功能清单（v1.0.0 已实现 ✅）

### 4.1 今日待办（Today's Tasks）
- ✅ 输入框 + 回车添加任务
- ✅ 点击 checkbox 标记完成/取消（已完成会加 `done` 样式 + 删除线）
- ✅ hover 显示 × 按钮，点击删除任务
- ✅ 右上角 badge 实时显示 `已完成 / 总数`
- ✅ 任务列表内部滚动（max-height 220px）
- ✅ **去重保护**：添加同名任务时弹出顶部 toast「哎呀，已经有「xxx」啦～ 别重复啦 🥺」，不创建重复项
- ✅ 数据按日期分组 `{ "2026-09-11": [todo, todo] }`，隔天数据独立

### 4.2 习惯打卡（Habit Tracker）
- ✅ 4 个默认习惯：💧 喝水 / 📖 阅读 / 🛌 早睡 / 🏃 运动
- ✅ 输入框 + emoji 选择器（16 个常用 emoji 分两行）
- ✅ "不选"选项（`/`）自动给默认图标 ⭐
- ✅ hover 习惯显示 × 删除按钮
- ✅ 右上角 badge 显示 `done / total`，**过滤掉了已删除习惯的孤立 id**（防止删除后虚高）
- ✅ 习惯列表全局存，打卡记录按日期存 `{ "2026-09-11": ["water", "read"] }`
- ✅ **去重保护**：添加同名习惯时弹出顶部 toast

### 4.3 心情日记（My Diary / Mood）
- ✅ 10 个心情 emoji 横向滚动选择（😊😌😴🥺🥰😡😰😎🎉🤔）
- ✅ 选中态：白玻璃底 + 2px 橙色实线细圈 + 2px 浅光环
- ✅ 一句话日记输入框（textarea）
- ✅ emoji 和 note **可独立保存**（只选 emoji 也行，只写文字也行）
- ✅ 按日期存 `{ "2026-09-11": { mood: "happy", note: "今天很开心" } }`
- ✅ 选中同一 emoji 会**取消选择**（可重置）

### 4.4 顶部欢迎区（Hero）
- ✅ 显示今天日期 + 星期几
- ✅ 主标题：「喵日常」
- ✅ 一句温暖的欢迎语：「今天也要好好生活呀～」
- ✅ 手绘 SVG 圆滚滚 Chiikawa 风小猫咪插画，轻轻浮动
- ✅ 右上角「📅 看历史」入口按钮

### 4.5 看历史（v1.0.0 超出 MVP 的彩蛋功能）
- ✅ 点击「📅 看历史」进入历史快照视图
- ✅ 进入历史默认看**昨天**（避免和今天混淆）
- ✅ **今天日期不可选**：日历上标"今天"小标签 + 灰显
- ✅ 当月日历（周一开头），左右箭头翻月份
- ✅ 日历卡可折叠/展开（默认展开，点击收起 ▲ / 展开 ▼）
- ✅ 历史模式下三个模块全部**只读**：
  - 表单隐藏
  - checkbox disabled
  - 心情 textarea disabled + 灰底
  - emoji 选项点击无反应
- ✅ 空态统一：「这天没有待办哦～」「这天没有打卡哦～」「这天没有记录心情哦～」白底圆角居中提示
- ✅ 「← 回到今天」按钮回到主视图

### 4.6 数据持久化
- ✅ LocalStorage 4 个 key：
  - `miao_daily_todos` — 待办 `{ "YYYY-MM-DD": [todo,...] }`
  - `miao_daily_habit_list` — 习惯列表 `[{ id, name, emoji }]`
  - `miao_daily_habit_records` — 打卡记录 `{ "YYYY-MM-DD": [habitId,...] }`
  - `miao_daily_mood` — 心情 `{ "YYYY-MM-DD": { mood, note } }`
- ✅ 刷新页面不丢失
- ✅ 首次访问有默认示例数据，帮助理解用法

## 6. 视觉规范

视觉规范的完整内容见 **`docs/UI_DESIGN_SPEC.md`**。简要概览：

- **风格**：温暖治愈奶油手账风
- **配色**：奶油米色 `#FFF8F0` 底 + 蓝 `#A8C8EC` / 粉 `#F4C2C2` / 橘 `#FAD4A3` 三色卡片
- **质感**：磨砂玻璃（`backdrop-filter: blur(24px)`）+ 4 色径向渐变背景 + 两个浮动模糊圆装饰
- **字体**：中文 PingFang SC，英文 Google Fonts Nunito
- **布局**：移动端优先，最大宽 480px
- **圆角**：卡片 24px，按钮 16px，toast 24px

## 7. 技术栈

- **HTML5**：语义化结构
- **CSS3**：自定义属性 + 渐变 + backdrop-filter + 动画（无 Tailwind 等框架依赖）
- **原生 JavaScript ES5+**：交互逻辑（不用框架，纯手写）
- **数据存储**：浏览器 LocalStorage
- **字体加载**：Google Fonts CDN（Nunito）
- **构建工具**：无（三文件直跑）
- **部署**：Vercel（推荐）或 GitHub Pages

## 8. 数据结构（v1.0.0 实际实现）

### 8.1 Task（待办）
```json
{
  "id": 1694401234567,
  "text": "读 30 分钟书",
  "completed": false
}
```
存储 key：`miao_daily_todos`，格式：`{ "YYYY-MM-DD": [task, ...] }`

### 8.2 Habit（习惯）+ Records（打卡）
```json
// 全局 habit 列表
[{
  "id": "water",
  "name": "喝水",
  "emoji": "💧"
}]

// 按天的打卡记录（只有 id 列表，不存其他）
{
  "2026-09-11": ["water", "read"]
}
```
存储 key：`miao_daily_habit_list` + `miao_daily_habit_records`

### 8.3 MoodEntry（心情）
```json
{
  "2026-09-11": {
    "mood": "happy",        // emoji id，null 表示未选
    "note": "今天很开心"      // 字符串，可空
  }
}
```
存储 key：`miao_daily_mood`
