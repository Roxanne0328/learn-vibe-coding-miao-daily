# PRD：喵日常（Mia's Cute Planner）

## 1. 项目基本信息

- **项目名称**：喵日常 / Mia's Cute Planner
- **项目类型**：个人生活办公工具（Web 单页应用）
- **目标用户**：咪咪大人本人，后期可分享给朋友使用
- **项目阶段**：V1.0.0 已达成 ✅
- **开发方式**：Vibe Coding，AI 结对编程
- **当前版本**：v1.0.0 MVP（2026-09-11）

## 2. 产品定位

一个温暖、可爱、无压力的日常计划网页。帮助用户记录当天要做的事、追踪日常习惯、快速记录心情。

核心体验：打开网页 → 看到今天 → 随手记录 → 获得一点小确幸。

## 3. 用户故事

1. 每天早上打开网页，看到今天的待办清单，勾选完成。
2. 做完一件小事后，给习惯打卡，看到连续打卡会有成就感。
3. 睡前想写一句今天的心情或感恩小事。
4. 刷新页面或关掉浏览器再打开，记录还在。
5. 能把网页链接发给朋友，朋友打开也能看到同款可爱界面。

## 4. 功能清单（MVP）

### 4.1 今日待办（Today's Tasks）
- 添加新任务（输入框 + 回车）
- 标记任务完成/取消完成
- 删除任务
- 显示今日完成进度（已完成 / 总数）

### 4.2 习惯打卡（Habit Tracker）
- 展示 3-5 个默认习惯（可后续扩展）
- 习惯示例：喝水 8 杯、早睡、阅读 30 分钟、运动
- 点击习惯卡片完成今日打卡
- 显示本周连续打卡天数

### 4.3 心情日记（My Diary / Mood）
- 选择今日心情图标（开心、平静、疲惫、难过、兴奋）
- 写一句今日心情/感悟（140 字以内）
- 保存后显示在最近心情记录区

### 4.4 顶部欢迎区
- 显示今天日期、星期几
- 一句温暖的欢迎语
- 可爱的装饰插画/SVG 占位

### 4.5 数据持久化（第一版）
- 使用浏览器 LocalStorage 保存所有数据
- 刷新页面不丢失
- 首次访问有默认示例数据，帮助用户理解用法

## 5. 不做什么（第一版明确排除）

- 用户登录/注册系统
- 跨设备云端同步
- 后端数据库
- 多用户协作
- 复杂的日历拖拽/重复任务设置
- 真实插画图片生成（第一版用 SVG/Emoji/色块代替，后续可替换）
- 导出 PDF / 邮件提醒等高级功能

> 说明：登录和云端同步是第二版目标。第一版先做出完整可用的网页，让数据在本机保存，避免项目一开始就陷入后端配置的复杂度。

## 6. 视觉规范

### 6.1 整体风格
- 温暖治愈的奶油系手账风
- 大圆角、柔和阴影、无锋利边缘
- 可爱但不幼稚，适合生活办公场景

### 6.2 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#FFF8F0` | 奶油米色 |
| 卡片背景 | `#FFFFFF` | 白色，带柔和阴影 |
| 主强调色 | `#FAD4A3` | 暖橙色 |
| 次要色 1 | `#A8C8EC` | 柔和蓝 |
| 次要色 2 | `#F4C2C2` | 柔和粉 |
| 文字主色 | `#5A4A42` | 温暖深棕 |
| 文字次色 | `#9E8E82` | 浅棕灰 |
| 完成态 | `#8BCA9A` | 柔和绿 |
| 删除/危险 | `#E8A0A0` | 柔和红 |

### 6.3 字体
- 中文字体：系统默认无衬线字体（PingFang SC / Microsoft YaHei）
- 英文字体：Nunito / Quicksand（通过 Google Fonts 引入）
- 标题略带圆润感，正文清晰易读

### 6.4 布局
- 移动端优先（手机友好）
- 最大宽度 480px 居中
- 卡片内边距 20-24px
- 圆角半径 16-24px

### 6.5 插画
- 第一版使用 SVG 简单图形或 Emoji 占位
- 后续可替换为真实可爱插画

## 7. 技术栈

- **HTML5**：页面结构
- **Tailwind CSS**：样式（通过 CDN 引入，无需配置构建工具）
- **原生 JavaScript**：交互逻辑、LocalStorage 读写
- **数据存储**：浏览器 LocalStorage
- **部署**：Vercel 或 GitHub Pages

## 8. 数据结构

### 8.1 任务（Task）
```json
{
  "id": "task_1694401234567",
  "text": "读 30 分钟书",
  "completed": false,
  "createdAt": "2026-09-11T08:00:00.000Z",
  "date": "2026-09-11"

```

### 8.2 习惯（Habit）
```json

  "color": "#A8C8EC",
  "records": ["2026-09-10", "2026-09-11"]

```

### 8.4 本地存储键名
- `mia_planner_tasks`
- `mia_planner_habits`
- `mia_planner_moods`
- `mia_planner_first_visit`

## 9. 验收标准

1. 页面在手机 Safari/Chrome 和电脑 Chrome 上正常显示。
2. 能添加任务、标记完成、删除任务。
3. 能点击习惯完成当日打卡，打卡状态当天有效。
4. 能选择心情并写一句话，保存后显示在记录区。
5. 刷新页面后，任务、习惯、心情记录不丢失。
6. 首次访问有默认数据，帮助用户理解功能。
7. 页面整体视觉符合奶油可爱风格，无严重配色冲突。
8. 所有交互有基础反馈（按钮点击、状态变化）。

## 11. 风险与应对

| 风险 | 应对方案 |
|------|----------|
| 零基础看不懂代码 | 每一行改动都带解释，关键步骤让 AI 先给方案再执行 |
| 功能越做越多收不住 | 严格按本 PRD 的 MVP 范围执行，新想法先记录到"后续版本" |
| LocalStorage 数据丢失 | 后续 V2 迁移到云端；V1 提供导出 JSON 备份入口 |
| 手机适配出问题 | 开发过程中用手机视图实时检查 |
